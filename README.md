# Event Hub

เว็บแอปพลิเคชันสำหรับค้นหาและจัดการกิจกรรมหรือค่าย พัฒนาด้วย **Next.js, React, TypeScript และ PostgreSQL (Neon)** ผู้ใช้สามารถค้นหากิจกรรม สมัครสมาชิก เข้าสู่ระบบ และสมัครเข้าร่วมกิจกรรม ส่วนผู้จัดกิจกรรมสามารถเพิ่มและจัดการกิจกรรมได้ตามสิทธิ์ และ Admin สามารถจัดการบทบาทของผู้ใช้

## คุณสมบัติหลัก

- แสดงรายการกิจกรรมในรูปแบบการ์ด พร้อมรายละเอียด ผู้จัด หมวดหมู่ รูปภาพ ราคา และจำนวนผู้สมัคร
- ค้นหากิจกรรมจากชื่อ รายละเอียด หรือชื่อผู้จัด
- กรองกิจกรรมตามรูปแบบออนไลน์/ออนไซต์ และหมวดหมู่
- สมัครสมาชิกและเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน
- สมัครเข้าร่วมกิจกรรมหรือยกเลิกการสมัคร
- ผู้ใช้ที่ได้รับบทบาท Event Creator สามารถเพิ่มกิจกรรมได้
- เจ้าของกิจกรรมและ Admin สามารถแก้ไขหรือลบกิจกรรมตามสิทธิ์
- Admin สามารถดูรายชื่อผู้ใช้ เปลี่ยนบทบาทเป็น User/Event Creator และลบบัญชีผู้ใช้ได้

## เทคโนโลยีที่ใช้

- Next.js 16 (App Router)
- React 19 และ TypeScript
- Tailwind CSS 4
- PostgreSQL ผ่าน Neon Serverless
- API Routes ของ Next.js

## วิธีติดตั้งและเริ่มใช้งาน

### 1. ดาวน์โหลดโปรเจกต์

```bash
git clone https://github.com/tthp143/event-hub.git
cd event-hub
```

### 2. ติดตั้งแพ็กเกจ

```bash
npm install
```

### 3. ตั้งค่าฐานข้อมูลและ Environment

คัดลอกไฟล์ตัวอย่าง `.env.example` เป็น `.env.local`

**Windows (Command Prompt):**
```bat
copy .env.example .env.local
```

**macOS / Linux:**
```bash
cp .env.example .env.local
```

เปิดไฟล์ `.env.local` แล้วกำหนดค่าต่าง ๆ:

```env
DATABASE_URL="ใส่ PostgreSQL connection string จาก Neon"
AUTH_SECRET="ใส่ secret แบบสุ่มที่ยาวและปลอดภัย"
ADMIN_USERNAME="admin"
ADMIN_PASSWORD="เปลี่ยนเป็นรหัสผ่านที่ปลอดภัย"
```

วิธีรับค่า `DATABASE_URL` จาก Neon:

1. สร้างโปรเจกต์และฐานข้อมูล PostgreSQL ใน Neon
2. เปิดหน้า Connection Details ของฐานข้อมูล
3. คัดลอก connection string ทั้งชุด แล้วนำไปแทนค่าตัวอย่างใน `DATABASE_URL`
4. ตรวจสอบว่าไม่มีข้อความ placeholder เช่น `USER`, `PASSWORD`, `HOST` หรือ `DATABASE` เหลืออยู่

สร้างค่า `AUTH_SECRET` ด้วยคำสั่งนี้ได้:

```bash
node -e "console.log(require('crypto').randomBytes(32).toString('base64'))"
```

คัดลอกผลลัพธ์ไปใส่ใน `AUTH_SECRET` แล้วบันทึกไฟล์ `.env.local` หากแก้ไขค่าระหว่างที่เซิร์ฟเวอร์ทำงาน ให้หยุดแล้วเปิดเซิร์ฟเวอร์ใหม่

> **สำคัญ:** อย่า commit ไฟล์ `.env.local` หรือเผยแพร่ connection string, secret และรหัสผ่าน Admin สู่สาธารณะ

### 4. เริ่มเซิร์ฟเวอร์สำหรับพัฒนา

```bash
npm run dev
```

เปิดเบราว์เซอร์ที่ [http://localhost:3000](http://localhost:3000)

หยุดเซิร์ฟเวอร์ได้โดยกด `Ctrl + C` ใน Terminal

## วิธีใช้งานหน้าแรก

หน้าแรกอยู่ที่ `/` และเป็นหน้าหลักสำหรับค้นหาและจัดการกิจกรรม องค์ประกอบที่สำคัญมีดังนี้

### 1. แถบด้านบน (Header)

- **Event Hub:** ชื่อระบบ
- **เข้าสู่ระบบ:** เปิดหน้าต่าง Login เพื่อกรอกชื่อผู้ใช้และรหัสผ่าน
- **สมัครสมาชิก:** เปิดหน้าต่างสมัครบัญชีใหม่
- **ชื่อผู้ใช้และ Role:** เมื่อเข้าสู่ระบบแล้วจะแสดงชื่อบัญชีและบทบาท
- **Dashboard:** แสดงเฉพาะ Admin ใช้จัดการบทบาทของผู้ใช้
- **เพิ่มกิจกรรม:** แสดงให้ Admin และ Event Creator ใช้เปิดแบบฟอร์มเพิ่มกิจกรรม
- **ออกจากระบบ:** ออกจากบัญชีที่กำลังใช้งาน

### 2. ค้นหาและกรองกิจกรรม

- **ช่องค้นหา:** พิมพ์ชื่อกิจกรรม รายละเอียด หรือชื่อผู้จัด
- **ตัวเลือกทุกรูปแบบ:** เลือกทั้งหมด, ออนไลน์ หรือออนไซต์
- **ตัวเลือกทุกหมวด:** กรองตามหมวด เช่น คอม/ไอที, วิศวกรรม, พัฒนาทักษะ/เวิร์กชอป, กิจกรรมออนไลน์ หรืออื่น ๆ
- **ปุ่มค้นหา:** ใช้ค้นหาตามเงื่อนไขที่เลือก

### 3. การ์ดกิจกรรม

การ์ดแต่ละใบแสดงรูปภาพ (ถ้ามี) ผู้จัด ชื่อกิจกรรม รายละเอียด รูปแบบกิจกรรม หมวดหมู่ ราคา และจำนวนผู้สมัคร

- **สมัครเข้าร่วม:** ผู้ใช้ที่เข้าสู่ระบบสามารถกดสมัครเข้าร่วมกิจกรรม
- **ยกเลิกการสมัคร:** หากสมัครแล้ว ปุ่มจะเปลี่ยนเป็นยกเลิกการสมัคร
- **แก้ไข:** เจ้าของกิจกรรมหรือ Admin สามารถเปิดแบบฟอร์มแก้ไขข้อมูลกิจกรรม
- **ลบ:** เจ้าของกิจกรรมหรือ Admin สามารถลบกิจกรรม โดยระบบจะแสดงกล่องยืนยันก่อนดำเนินการ
- หากยังไม่ได้เข้าสู่ระบบ ระบบจะแสดงปุ่มให้เข้าสู่ระบบก่อนสมัคร
- หากไม่มีรายการตรงกับคำค้นหา ระบบจะแสดงข้อความว่าไม่พบกิจกรรมที่ตรงกับการค้นหา

### 4. แบบฟอร์มสมัครสมาชิกและเข้าสู่ระบบ

กดปุ่ม **สมัครสมาชิก** หรือ **เข้าสู่ระบบ** บนแถบด้านบนเพื่อเปิดหน้าต่างแบบฟอร์ม จากนั้นกรอกข้อมูลและส่งแบบฟอร์ม หากต้องการปิดหน้าต่าง ให้คลิกบริเวณพื้นหลังนอกแบบฟอร์ม

บัญชีที่สมัครใหม่จะได้รับบทบาท `USER` และยังไม่สามารถสร้างกิจกรรมได้จนกว่า Admin จะเปลี่ยนบทบาทให้เป็น `CREATOR`

### 5. เพิ่มหรือแก้ไขกิจกรรม

Admin และ Event Creator สามารถเปิดแบบฟอร์มเพิ่มกิจกรรมจากปุ่ม **เพิ่มกิจกรรม** ส่วนการแก้ไขทำได้จากปุ่ม **แก้ไข** บนการ์ดกิจกรรมที่มีสิทธิ์จัดการ

กรอกข้อมูลกิจกรรมในแบบฟอร์ม เช่น ชื่อกิจกรรม รายละเอียด รูปภาพ ผู้จัด ราคา รูปแบบ และหมวดหมู่ จากนั้นบันทึกข้อมูล ระบบจะโหลดรายการกิจกรรมใหม่เพื่อแสดงผลล่าสุด

## วิธีใช้งาน Dashboard (สำหรับ Admin)

เปิดหน้า `http://localhost:3000/dashboard` หรือกดปุ่ม **Dashboard** หลังเข้าสู่ระบบด้วยบัญชี Admin

- ตารางแสดงชื่อผู้ใช้และบทบาทปัจจุบัน
- ใช้ช่องเลือก Role เพื่อเปลี่ยนบทบาทระหว่าง `USER` และ `CREATOR`
- กดปุ่ม **ลบ** เพื่อลบบัญชีผู้ใช้ โดยระบบจะแสดงกล่องยืนยันก่อนลบ
- กด **กลับหน้าแรก** เพื่อกลับไปยังรายการกิจกรรม

ผู้ใช้ที่ไม่ใช่ Admin จะไม่สามารถใช้ฟังก์ชันจัดการผู้ใช้ได้

## บทบาทของผู้ใช้

| บทบาท | สิทธิ์หลัก |
| --- | --- |
| `USER` | ค้นหาและสมัครเข้าร่วมกิจกรรม |
| `CREATOR` | สิทธิ์ของ User และสามารถเพิ่มกิจกรรม รวมถึงจัดการกิจกรรมของตนเอง |
| `ADMIN` | จัดการกิจกรรมทั้งหมด และจัดการบทบาท/บัญชีผู้ใช้ผ่าน Dashboard |

Admin สามารถกำหนดสิทธิ์ Event Creator ให้บัญชีที่สมัครสมาชิกแล้วผ่าน Dashboard

## การแก้ปัญหาเบื้องต้น

- **แจ้งว่าไม่ได้ตั้งค่า DATABASE_URL:** ตรวจสอบว่าไฟล์ `.env.local` อยู่ที่โฟลเดอร์หลักและมีค่า connection string จาก Neon ที่ถูกต้อง
- **แจ้งว่า DATABASE_URL ยังเป็น placeholder:** แทนค่าตัวอย่างทั้งหมดด้วย connection string จริงจากหน้า Connection Details ของ Neon
- **เชื่อมต่อฐานข้อมูลไม่ได้:** ตรวจสอบว่า Neon project ยังทำงานอยู่, connection string ถูกต้อง และเครือข่ายเชื่อมต่อได้
- **แก้ไข Environment แล้วไม่เปลี่ยน:** หยุดเซิร์ฟเวอร์ด้วย `Ctrl + C` แล้วรัน `npm run dev` ใหม่
- **สมัครสมาชิกหรือเข้าสู่ระบบไม่ได้:** ตรวจสอบข้อมูลที่กรอกและดูข้อความแจ้งเตือนบนหน้าเว็บ
- **ไม่เห็นปุ่มเพิ่มกิจกรรม:** บัญชีต้องเป็น `ADMIN` หรือ `CREATOR`; หากเป็น `USER` ให้ Admin เปลี่ยนบทบาทผ่าน Dashboard
- **เข้า Dashboard ไม่ได้:** ต้องเข้าสู่ระบบด้วยบัญชีที่มีบทบาท `ADMIN`

## การ Build สำหรับ Production

ก่อนนำไปใช้งานบนเซิร์ฟเวอร์จริง ให้ตั้งค่า Environment Variables ที่ระบบ Hosting โดยใช้ค่าเดียวกับที่จำเป็นใน `.env.local` จากนั้นทดสอบ:

```bash
npm run build
npm run start
```

อย่าใช้รหัสผ่านตัวอย่างหรือเผยแพร่ secret ในระบบ Production
